② 这是什么

「麦麦管家」是一个跑在 WorkBuddy（及任意支持 MCP 的 Agent）里的技能，接入麦当劳中国官方 MCP Server （mcp.mcd.cn，24 个工具）。它把"翻 App 比价、找券、查积分"压缩成一句话，并提供一个别的封装做不到的能力——

核心创新省钱最优解引擎：给定预算，自动组合「菜单 + 优惠券 + 价格试算」，枚举单人餐 / 双人分享餐， 匹配满减、买一送一、单品立减、第二件半价等券规则，输出"省得最多 + 吃得最值"的 Top3 组合。

③ 怎么跑起来

零依赖 Python 客户端（仅需标准库）：

python scripts/mcd_mcp.py save --budget 60 --demo  ← 离线演示（无需 Token）

python scripts/mcd_mcp.py save --budget 60  ← 真实调用（需 MCD_MCP_TOKEN）

或直接在 WorkBuddy 里说："60 块以内帮我配两个人吃的，怎么点最省"。
