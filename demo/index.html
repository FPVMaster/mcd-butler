② 这是什么

「麦麦管家」是一个跑在 WorkBuddy（及任意支持 MCP 的 Agent）里的技能，接入麦当劳中国官方 MCP Server （mcp.mcd.cn，实测 37 个工具）。它把"翻 App 比价、找券、查积分"压缩成一句话，并提供一个别的封装做不到的能力——

核心创新省钱最优解引擎：给定预算，自动走 query-nearby-stores → query-meals 拉取门店真实菜单与官方现价/原价， 按官方折扣力度排序，输出"省得最多"的 Top3 套餐，并提示可叠加的优惠券——省额全部来自官方数据，无任何虚构。

③ 怎么跑起来

零依赖 Python 客户端（仅需标准库）：

python scripts/mcd_mcp.py save --budget 60 --demo  ← 离线演示（无需 Token）

python scripts/mcd_mcp.py save --budget 60  ← 真实调用（需 MCD_MCP_TOKEN）

或直接在 WorkBuddy 里说："60 块以内帮我配两个人吃的，怎么点最省"。
